/*
WoW Model Viewer — Build Notes

-=Libraries=-
GLFW, Dear ImGui (docking branch), glad (OpenGL 4.6 compat loader),
CASCLib, pugixml, zlib, libpng, FBX SDK, stb_image_write, glm.

-=Build Instructions=-
1. Open the repository root with Visual Studio (CMake preset: x64-Debug or x64-Release).
   Alternatively, configure from the command line:
	 cmake -G Ninja -B build -DCMAKE_BUILD_TYPE=Release
2. First-time setup runs scripts/setup_x64_deps.ps1 automatically to fetch
   third-party binaries (FBX SDK, zlib, libpng, wxWidgets, etc.).
3. Build:
	 cmake --build build
4. The ImGui-based viewer is built as wowmodelviewer_imgui.
5. Runtime files (database.xml, AnimationData.csv, etc.) are installed to
   bin/games/wow/<version>/ by the install step.

-=Program Flow (ImGui target)=-
main_imgui.cpp is the single entry point. It initialises GLFW, OpenGL, and
Dear ImGui, then runs the main loop which includes:
  - Game loading (CASCLib, listfile, WoWDatabase)
  - File Browser (filterable CASC tree view)
  - Model loading (WoWModel, character equipment, animations)
  - 3D Viewport (off-screen FBO rendered as ImGui::Image)
  - Animation / Model Control / Character / Lighting panels
  - NPC Browser, Item Browser, Export, Screenshot, Presets

Engine libraries (Source/core, Source/games/wow) provide model parsing,
texture management, animation, and database access.

-=Updating Notes=-
When updating a support library, be careful not to over-write modified files.
Back up and test before committing.

*/
